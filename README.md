# LLM Engineering

This repository contains my hands-on learning journey in **LLM Engineering and Generative AI**. It includes practical exercises, experiments, and projects focused on understanding and building applications with Large Language Models.

## Topics Covered

- Large Language Models (LLMs)
- Generative AI
- Prompt Engineering
- OpenAI-compatible APIs
- Open-source and open-weight models
- Model experimentation and comparison
- Multi-agent and multi-turn conversations
- Retrieval-Augmented Generation (RAG)
- Embeddings and Vector Databases
- Tool Calling and AI Agents
- LLM Application Development

The goal of this repository is to build practical knowledge of LLMs by implementing concepts through hands-on exercises and progressively more advanced projects.
